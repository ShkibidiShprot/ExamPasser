# ExamPasser

> Минималистичное кроссбраузерное расширение для анализа видимой части экрана с помощью Gemini API.

ExamPasser делает скриншот текущей вкладки вручную или по расписанию, отправляет его в Gemini и показывает компактный ответ в правом нижнем углу страницы.

**Языки:** [English](README.md) · [Українська](README.uk.md) · [Русский](README.ru.md)

## Возможности

- Manifest V3.
- Поддержка Chrome, Opera/Opera GX, Firefox и Zen Browser.
- Анализ видимой области вкладки.
- Ручной режим по горячей клавише.
- Автоматический режим с интервалом от 20 секунд.
- Компактный оверлей с закрытым Shadow DOM.
- Украинский, русский и английский интерфейс.
- Быстрая модель `gemini-3.5-flash-lite`.
- Настройка прозрачности ответа.
- API-ключ и настройки хранятся локально.

## Как получить API-ключ

1. Открой [Google AI Studio](https://aistudio.google.com/apikey).
2. Войди в Google-аккаунт.
3. Нажми **Create API key**.
4. Скопируй ключ и вставь его в ExamPasser.
5. Нажми **Сохранить настройки**.

Не публикуй и не передавай API-ключ. Каждый пользователь должен использовать собственный ключ.

## Установка в Chrome или Opera GX

1. Склонируй или скачай этот репозиторий.
2. Открой `chrome://extensions` в Chrome или `opera://extensions` в Opera GX.
3. Включи **Developer mode**.
4. Нажми **Load unpacked**.
5. Выбери корневую папку с `manifest.json`.
6. Закрепи ExamPasser на панели браузера.

Не перемещай и не удаляй выбранную папку.

## Установка в Firefox или Zen Browser

Для Firefox используется `manifest.firefox.json`. Для постоянной установки нужен подписанный Mozilla файл `.xpi`.

1. Отправь Firefox-версию через [Mozilla Add-on Developer Hub](https://addons.mozilla.org/developers/addon/submit/).
2. Выбери непубличное распространение (**Unlisted**).
3. После проверки скачай подписанный `.xpi`.
4. Открой `about:addons`.
5. Нажми шестерёнку → **Install Add-on From File**.
6. Выбери `.xpi`.

## Управление

- Стандартная команда: `Alt+Q`.
- Альтернативная команда: `Alt+Shift+Q`.
- Горячую клавишу можно изменить в меню расширения или настройках браузера.
- Ручной режим запускает анализ по горячей клавише.
- Автоматический режим запускает анализ через выбранный интервал.

## Приватность

Скриншот отправляется в Google Gemini API только после запуска анализа. Собственного сервера у ExamPasser нет. API-ключ и остальные настройки хранятся в локальном хранилище браузера.
