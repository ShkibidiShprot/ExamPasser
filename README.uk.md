# ExamPasser

> Мінімалістичне кросбраузерне розширення для аналізу видимої частини екрана за допомогою Gemini API.

ExamPasser робить скриншот поточної вкладки вручну або за розкладом, надсилає його до Gemini та показує компактну відповідь у правому нижньому куті сторінки.

**Мови:** [English](README.md) · [Українська](README.uk.md) · [Русский](README.ru.md)

## Можливості

- Manifest V3.
- Підтримка Chrome, Opera/Opera GX, Firefox і Zen Browser.
- Аналіз видимої області вкладки.
- Ручний режим за гарячою клавішею.
- Автоматичний режим з інтервалом від 20 секунд.
- Компактний оверлей із закритим Shadow DOM.
- Українська, російська та англійська мови інтерфейсу.
- Швидка модель `gemini-3.5-flash-lite`.
- Налаштування прозорості відповіді.
- API-ключ і налаштування зберігаються локально.

## Отримання API-ключа

1. Відкрий [Google AI Studio](https://aistudio.google.com/apikey).
2. Увійди у Google-акаунт.
3. Натисни **Create API key**.
4. Скопіюй ключ і встав його в ExamPasser.
5. Натисни **Зберегти налаштування**.

Не публікуй і не передавай API-ключ. Кожен користувач має використовувати власний ключ.

## Встановлення у Chrome або Opera GX

1. Клонуй або завантаж цей репозиторій.
2. Відкрий `chrome://extensions` у Chrome або `opera://extensions` в Opera GX.
3. Увімкни **Developer mode**.
4. Натисни **Load unpacked**.
5. Вибери кореневу папку з `manifest.json`.
6. Закріпи ExamPasser на панелі браузера.

Не переміщуй і не видаляй вибрану папку.

## Встановлення у Firefox або Zen Browser

Для Firefox використовується `manifest.firefox.json`. Для постійного встановлення потрібен підписаний Mozilla файл `.xpi`.

1. Відправ Firefox-версію через [Mozilla Add-on Developer Hub](https://addons.mozilla.org/developers/addon/submit/).
2. Обери непублічне розповсюдження (**Unlisted**).
3. Після перевірки завантаж підписаний `.xpi`.
4. Відкрий `about:addons`.
5. Натисни шестерню → **Install Add-on From File**.
6. Вибери `.xpi`.

## Керування

- Стандартна команда: `Alt+Q`.
- Альтернативна команда: `Alt+Shift+Q`.
- Власну гарячу клавішу можна налаштувати в меню розширення або браузері.
- Ручний режим запускає аналіз за гарячою клавішею.
- Автоматичний режим запускає аналіз через вибраний інтервал.

## Приватність

Скриншот надсилається до Google Gemini API лише після запуску аналізу. Власного сервера ExamPasser не має. API-ключ та інші налаштування зберігаються в локальному сховищі браузера.
